## Запуск в Windows

Проверено на Python 3.11. В терминале из корня репозитория:

```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r ".\Задание 1\requirements.txt"
.\.venv\Scripts\python.exe -m ipykernel install --user --name hse-ml --display-name "ML (Python 3.11)"
```

В VS Code выберите ядро **ML (Python 3.11)** или интерпретатор `.venv\Scripts\python.exe`. Перезапустите ядро и выполните все ячейки. CSV должен находиться рядом с ноутбуком. Настройка проекта уже задаёт рабочую папку по расположению `.ipynb`.

Для macOS/Linux можно создать `.venv` через `python3.11 -m venv .venv` и выбрать `.venv/bin/python` в VS Code.
