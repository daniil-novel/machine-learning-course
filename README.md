## Как работать в VS Code

1. Скачайте архив нужной ветки или переключитесь на неё через меню веток.
2. Откройте корневую папку репозитория в VS Code.
3. Установите рекомендованные расширения Python и Jupyter, если их ещё нет.
4. Выполните настройку Python из README нужного задания.
5. Откройте `.ipynb` и выберите ядро в правом верхнем углу. Затем используйте «Выполнить всё» или `Shift+Enter` для одной ячейки.

Настройки редактора находятся в `.vscode`. Локальное окружение `.venv` в Git не хранится.
